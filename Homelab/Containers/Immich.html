Immich Hardware Transcoding Fix (Rootless Podman/RHEL)

Issue: AssetEncodeVideo jobs failed with Error: No /dev/dri devices found. Context: Intel 1245U (QuickSync), Rootless Podman, RHEL. Cause: Rootless user not in render group + missing device mapping in compose.

Solution

  1. Host Permissions:
    • Verify device owner: ls -l /dev/dri/renderD128 (Output: root render).
    • Add user to group: sudo usermod -aG render $USER.
    • Action: Log out and log back in.
  2. Compose Config (docker-compose.yml): Add devices mapping to both immich-server and immich-machine-learning or similar: ```yaml devices: /dev/dri:/dev/dri
